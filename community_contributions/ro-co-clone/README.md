# ro.co marketing clone (local demo)

A Vite + React recreation of the **ro.co** top-of-funnel marketing experience.

Not affiliated with Ro. Uses original/placeholder copy. Structure and interaction patterns are approximated for local demo only.

## Run

```sh
cd community_contributions/ro-co-clone
npm install
npm run dev
```

Open the printed local URL (default `http://127.0.0.1:5173`).

## Pages

- `/` home marketing composition
- `/weight-loss` category + projection widget + FAQ
- `/sexual-health`, `/hair`, `/skin` category landings
- `/visit` multi-step online-visit prototype
